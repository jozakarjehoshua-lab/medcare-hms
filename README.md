# MedCare HMS — Hospital Management System

A desktop Hospital Management System developed using Python, Tkinter, and SQLite. MedCare HMS is a learning and portfolio project designed to demonstrate desktop application development, database integration, and the organization of common hospital administration tasks.

## Overview

MedCare HMS provides a graphical interface for managing hospital-related information through separate application modules. The project is being developed to improve practical skills in Python programming, GUI design, database management, and software development.

## Features and Modules

- **Login:** User login interface.
- **Dashboard:** Central interface for accessing application modules.
- **Patient Management:** Patient registration and patient information management.
- **Doctor Management:** Doctor-related management module.
- **Appointments:** Appointment management module.
- **Medical Records:** Medical-record management module.
- **Billing:** Billing module.
- **Database Integration:** SQLite database integration for storing application data.

## Technologies Used

- **Programming language:** Python
- **GUI framework:** Tkinter
- **Database:** SQLite
- **Version control:** Git
- **Code hosting:** GitHub

## Database and Privacy

MedCare HMS uses SQLite for local data storage. The local database file is excluded from version control through `.gitignore`.

**Important:** This project is intended for educational and portfolio purposes. Use fictional demonstration data only. It has not been presented as a certified or production-ready clinical system and should not be used to store real patient information.
